# Brand images

These are the project's logo and its bot marks, each a square PNG with a transparent background.

| File | What it is |
| --- | --- |
| `open-software-factory-logo.png` | The project logo, in blue |
| `open-software-factory-bot-blue.png` | The bot mark in blue, for an automation identity |
| `open-software-factory-bot-green.png` | The bot mark in green |
| `open-software-factory-bot-red.png` | The bot mark in red |
| `open-software-factory-bot-brown.png` | The bot mark in brown |

The bot marks add a small robot badge to the logo. Each automation identity, such as a builder app or a verifier app, can use its own colour so a reader can tell them apart at a glance.
