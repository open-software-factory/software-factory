# OpenHands and agent platforms

## Prior research topic

The project previously compared OpenHands with the proposed software factory.

Use these scopes when re-checking the current OpenHands architecture:

- agent platforms/harnesses focus heavily on giving coding agents environments, tools and loops for completing software tasks;
- the software-factory vision is broader: provider-neutral orchestration, deterministic quality/security gates, lifecycle traceability, architectural fitness, trust calibration, multi-agent scheduling and eventually product-loop feedback.

## What to investigate when relevant

- OpenHands runtime/sandbox model.
- Agent/controller separation.
- Event/state representation.
- Tool/plugin extension model.
- Multi-agent/concurrency capabilities.
- Evaluation and verification boundaries.
- Remote execution model.
- What can be reused or integrated instead of rebuilt.

Do not assume this note reflects current OpenHands capabilities; treat it as a comparison checklist.
